# Aetheris Architecture

## Stage 1

Aetheris currently uses a small distributed architecture consisting of an API gateway, one independent user microservice, and PostgreSQL.

The design will evolve toward identity, rate limiting, event messaging, observability, resilience, AI-agent governance, and local Kubernetes deployment.

## Principles

- Clear service boundaries
- Secure-by-design architecture
- Observable components
- Reproducible local development
- Zero mandatory recurring software cost
- Interview-grade documentation and engineering rationale
