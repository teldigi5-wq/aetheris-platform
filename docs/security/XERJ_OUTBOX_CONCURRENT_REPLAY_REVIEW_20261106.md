## Important limitations
- The ACK-gap case simulates a worker crash by withholding a delivery DB transition and expiring the lease: it does **not** kill a production process or prove all failure-ordering cases. The deduplication guarantee is scoped to a single `event_id` and the existing Audit PK; it does not give broker exactly-once processing, global ordering or guaranteed delivery under all network partitions.
- Eight workers and 24 rows in hosted PostgreSQL is a correctness smoke test, **not** a stress capacity benchmark or formal linearizability proof. More randomized multi-JVM, pool exhaustion, Postgres restart and lease TTL failure injection are still required.
- Parked outbox events have no production-approved operator replay mechanism. An operator review must record identity, ticket, reason, privacy/regulatory treatment and a bounded idempotent replay request; never expose a client HTTP replay endpoint.
- `user_event_outbox` contains PII requiring retention, access controls, encrypted backup and erasure review. Production additive schema backup/migration, AMQPS identity, JWT revocation, true tenant-organization membership, Redis AUTH, DB roles, HSM/PKI and Stage45 attestations remain open.
